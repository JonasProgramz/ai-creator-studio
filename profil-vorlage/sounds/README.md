# Sounds

Soundeffekte und Musik (mp3 oder wav). Die Dateinamen stehen so in `effekte.json` der Videos. Woher sie kommen, steht in `profil.md`: eigene Dateien, frei lizenzierte Downloads, die du selbst lädst, oder von Claude über ElevenLabs erzeugt. Leg nur Dateien ab, die du nutzen darfst. Ohne Dateien hier bleibt das Video ohne Effekte.
